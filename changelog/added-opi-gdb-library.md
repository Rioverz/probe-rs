OPI downstream fork addition (not an upstream probe-rs release feature): added the `probe-rs-gdb` crate, which exposes the probe-rs GDB server as a library that serves the RSP protocol over a caller-owned, borrowed `Session` instead of enumerating and opening the probe a second time. The RSP engine files are extracted from the pinned `probe-rs-tools` GDB source with the documented library-exposure and test-module deltas, and verified by a deterministic drift check against a committed hash baseline; see `probe-rs-gdb/EXTRACTION.md`.
