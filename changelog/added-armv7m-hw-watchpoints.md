Added hardware data watchpoints on ARMv7-M cores (Cortex-M3, M4, M7) through the same API as ARMv6-M. Reading the comparator count or setting a watchpoint sets DEMCR.TRCENA first, and it stays set until the session detaches. Clearing all watchpoints, as a dropped session does, disables every comparator with no listing and one flush, including ones a trace setup programmed. New defaulted `CoreInterface` methods: `set_listed_hw_watchpoint` sets a unit the caller has just listed, `clear_all_hw_watchpoints` disables every unit.
