OPI downstream fork change (not an upstream probe-rs release feature): added `DownloadOptions::preserve_prepared_target_clock`, an opt-in flag that skips the flash-setup reset-and-halt when the caller has already halted the target, so a clock the caller prepared before flashing is preserved. It defaults to off (stock reset-and-halt behavior is unchanged); when enabled it requires an already-halted core and otherwise fails closed with the new `FlashError::PreparedTargetNotHalted`.
